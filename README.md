# expense-audit

Скилл для аудита расходов.

Анализирует CSV/Excel файл с расходами: общая сумма, разбивка по категориям, крупнейшие траты,
дубликаты, аномальные и отрицательные суммы — и пишет понятную сводку для владельца бизнеса.

- `SKILL.md` — инструкция для Claude (как получить файл, запустить аудит и написать сводку)
- `audit.py` — скрипт расчёта, без сторонних зависимостей (нужен только Python 3)

## Установка скилла в Claude Code

```bash
git clone https://github.com/wrkatp/expense-audit ~/.claude/skills/expense-audit
```

После этого достаточно попросить Claude: «Проверь расходы в файле ~/Downloads/expenses.csv».

## Запуск скрипта вручную

```bash
python3 audit.py expenses.csv                      # отчёт в report.txt
python3 audit.py statement.xlsx -o report.txt      # Excel
python3 audit.py file.csv --amount-col "Сумма"     # если столбец определился неверно
```

Столбцы с датой, категорией, описанием и суммой определяются автоматически — по заголовкам
(на русском или английском) или по содержимому. Поддерживаются разделители `,` `;` и табуляция,
кодировки UTF-8 и Windows-1251, банковские выписки с «шапкой» и расходами со знаком минус.
